# V3 整理接管：持久任务内的批量执行

本实现采用方案 A，适用于 `plugins.v3/p115strmhelper`。开启「接管网盘整理」，存储模块选择「115网盘Plus」后，同账号文件移动、复制和重命名仍可合并为批量网盘请求

V2 的行为参考保留在 [BATCH_TRANSFER_DESIGN.md](BATCH_TRANSFER_DESIGN.md)。V2 源码不变；V3 不再使用独立任务队列接收后立即返回成功

## 执行流程

1. MoviePilot 创建原持久任务，完成媒体识别、目标命名、计划冻结和租约领取
2. 插件给符合条件的计划增加批量标记；关联模式下，把匹配的字幕和音轨一并写入冻结计划
3. 每个任务继续执行宿主覆盖策略、插件拦截和目标目录准备
4. 原任务登记持久步骤，然后等待批量协调器。协调器按存储实例、动作和目标目录合并请求，默认等待 0.25 秒，每批最多 500 项
5. 逐文件确认实际结果，完成落地、重命名步骤后，再交回原宿主任务
6. 宿主原子提交历史、任务终态与完成事件；关联文件历史和事件加入同一事务。通知、刮削继续使用原宿主任务与作业聚合

宿主只有一个常规整理 worker 时，插件会临时增加运行宿主原生队列循环的辅助 worker，使多个原任务能进入同一批请求。辅助 worker 只领取匹配的网盘文件，空闲后退出

## 保留的功能

| 功能 | V3 行为 |
| --- | --- |
| 批量移动 | 合并 `fs_move`，实际确认目标，保留原文件 ID 和 pickcode |
| 批量复制 | 合并 `fs_copy`，按目标目录基线、新 ID、名称、大小和 SHA1 确认副本，使用副本的 pickcode |
| 批量重命名 | 独立持久步骤合并 `fs_rename`，重命名失败后不会重新移动或复制 |
| 关联字幕／音轨 | 沿用 V2 匹配、语言标签和命名规则；单独入队的关联文件任务跳过重复操作 |
| 独立字幕／音轨 | 关闭关联模式后，按独立原任务整理 |
| 覆盖与扩展事件 | 执行宿主 `never`、`size`、`always`、`latest` 及覆盖检查、整理拦截事件 |
| 预览 | 使用宿主预览结果，不写云端、不创建执行步骤、不扫描关联目录 |
| 历史和事件 | 原任务原子结算，关联文件逐文件记录，重放结算不会重复追加事件 |
| 源目录清理 | 成功移动后按 V2 边界清理，不删除下载器种子或修改种子状态 |
| 缓存 | 更新宿主实际选中的存储实例，不另外构造 P115Api |
| 非接管任务 | 其他存储、目录、音乐及其他整理方式继续走宿主原流程 |

关联文件在同一个主任务中依次执行持久步骤，能够与其他并行主任务的文件合并请求；不保证单个视频及其全部附件恰好合并在一次网盘请求中

## 失败与恢复

- **响应丢失或进程中断**：先观察真实云端状态，再决定完成步骤或重试，不直接重复复制
- **移动／复制成功，重命名失败**：保留落地文件身份，只恢复尚未完成的步骤
- **批量请求部分成功**：按文件分别确认，成功项继续，确定未生效的失败项交给宿主重试
- **无法确认结果或存在多个匹配副本**：进入宿主人工复核，避免自动创建更多副本
- **租约失效**：旧任务不能登记新步骤；发起批量请求前再次检查原任务租约
- **关联文件最终失败**：保留主视频和已完成附件的实际身份及历史；已完成主视频仍有完成事件供 STRM 处理，失败附件有独立失败事件。原任务保留部分失败状态，便于定位与恢复
- **历史／事件提交失败**：同一事务回滚，宿主重放结算；不因数据库失败再次操作云端文件
- **停止时仍有任务**：等待原任务和在途批次退出后再解除补丁，超时保留运行对象，不提前宣告停止完成

已有批量持久计划需要此插件的批量扩展才能恢复。存在待重试或人工复核任务时，应先处理这些任务，再关闭整理接管或卸载插件

## 代码位置

| 文件 | 职责 |
| --- | --- |
| `patch/transfer_chain.py` | 安装和恢复宿主补丁、传递原任务上下文、锁定冲突路径 |
| `helper/transfer/batch.py` | 收集和合并操作，逐文件返回真实结果 |
| `helper/transfer/workers.py` | 临时运行宿主原生 worker |
| `helper/transfer/planning.py` | 冻结关联文件计划并执行原生前置策略 |
| `helper/transfer/durable.py` | 目标基线、移动／复制、重命名及结果确认 |
| `helper/transfer/validation.py` | 仅允许冻结计划和成功步骤证据派生的扩展操作 |
| `helper/transfer/settlement.py` | 关联文件原子结算、部分失败证据与完成事件 |
| `helper/transfer/cleanup.py` | 按原边界清理源目录 |

实现使用经过宿主源码核对的内部 patch，不需要修改 MoviePilot 源码，也不增加插件数据库迁移。上游整理内部契约变化时，由真实宿主加载测试和批量契约测试发现不兼容
